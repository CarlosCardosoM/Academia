# 🏋️ Sistema de Gestão para Academia

Sistema desenvolvido em **Java** com foco em **Programação Orientada a Objetos (POO)** para gerenciamento administrativo e operacional de uma academia.

## 📌 Sobre o Projeto

O projeto tem como objetivo centralizar e automatizar processos internos de uma academia, permitindo o gerenciamento de alunos, funcionários, aulas, produtos, estoque, vendas e agendamentos em uma única aplicação.

Durante o desenvolvimento foram aplicados conceitos de **orientação a objetos**, **modularização**, **persistência de dados** e **organização das regras de negócio**, proporcionando uma experiência prática de construção de sistemas reais.

---

## 🚀 Funcionalidades

* Cadastro, alteração, remoção e listagem de alunos
* Gerenciamento de funcionários e gerentes
* Controle de aulas e agendamentos
* Venda de produtos e mensalidades
* Controle de estoque
* Registro e acompanhamento de operações
* Sistema de autenticação e login
* Persistência de dados utilizando arquivos JSON
* Organização modular utilizando classes e responsabilidades definidas
